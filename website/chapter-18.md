# 第 18 章　Agent 调优总览和实践

本章由《Agent 调优总览》打头，先把数据飞轮的整体图景讲清楚：Agent 上线之后还要持续回答哪些问题，轨迹、数据处理、数据集、评估、实验和优化各自承担什么，以及怎样从一个具体业务问题开始，把第一轮调优做完。

其余文章是一线团队把这套流程真正跑起来的记录。《Agent 数据飞轮平台的选型和实践》来自 1688 的组织经营大脑“宙斯”：为什么在几个评测方案里选了 AgentLoop，探针怎么挂、Trace 怎么验收、评估任务怎么配，接入过程踩过哪些坑，以及线上巡检、实验验证和发布准出跑通之后，定位时间、回归耗时和复发率各自变成了什么样。后续的 Agent 调优实践文章会继续收录在本章。
