# Personal Agent 专题

本专题关注 Personal Agent 的产品路线、技术挑战与商业化方向，以及支撑个人助手和企业智能体持续工作的服务架构。

《Personal Agent 产品技术与商业观察》梳理十款产品的设计路线，拆解全天候运行、状态恢复、权限、记忆与完成验证等技术挑战，并讨论 C 端免费入口与 B 端数字员工两条商业化方向。文中的产品信息截至发文时，部分来自厂商公开资料与社区反馈。

《从 Personal Agent 到企业智能体：AgentScope 的 Agent as a Service 架构》以 AgentScope 为基础，讨论 Harness 远端托管、本地与远端执行交接、Context 与 Memory 的云端管理，以及 Brain／Hands 分离，并介绍如何通过 AgentCore 承载自建的 Agent 服务。
