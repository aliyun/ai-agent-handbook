# 推理框架专题：模型上线之后的那一层

本专题面向第一次接触推理框架的读者，讲清楚模型训练好之后，是靠什么被高效、稳定地交付到每一个请求手中的。推理框架位于 Agent 应用和 GPU 集群之间，日常通过 API 使用模型时不太会注意到它，但首字等多久、并发上来会不会变慢、缓存命中能省多少钱，都由这一层决定。

首篇文章依次介绍推理框架和模型、智能体的关系，阅读所需的几个基础概念，主流开源推理框架的发展脉络，一个请求在推理框架内部经过的入口、调度、执行、缓存、集群和采样六个环节，以及哪些人群和企业会用到推理框架。文中只梳理项目来历和发展情况，不做优劣比较；项目信息和星标数截至 2026 年 10 月。
